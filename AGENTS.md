# Kontext pracovného priestoru

Tento súbor je trvalý kontext pre AI asistenta pri práci v tomto pracovnom priestore. Pred zmenami si ho prečítaj a po dokončení práce ho aktualizuj.

## Projekt

- Pracovný priečinok: `wp-content/plugins/sprava-bytov`
- Pravdepodobné zaradenie: WordPress plugin podľa umiestnenia priečinka. Konkrétnu funkcionalitu, architektúru a používané technológie treba zistiť z projektových súborov; nič z toho zatiaľ nie je potvrdené.
- Pri vytvorení tohto súboru sa v priečinku nenachádzali žiadne projektové súbory ani Git metadáta.

## Pravidlá práce

- Vždy komunikuj s používateľom po slovensky.
- Pred úpravou preskúmaj relevantné súbory a existujúce konvencie. Zachovaj aktuálnu architektúru a rozsah požiadavky.
- Rob malé, súvisiace zmeny; neupravuj ani neodstraňuj nesúvisiacu prácu.
- Po zmene spusti dostupné relevantné kontroly. Zaznamenaj, čo bolo spustené a či prešlo; neuvádzaj neoverené výsledky ako úspešné.
- Chyby, predpoklady a nevyriešené otázky uveď otvorene.
- Nepíš do tohto súboru tajomstvá, prihlasovacie údaje ani osobné údaje.
